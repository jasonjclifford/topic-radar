Relaywork 0.9 adds parallel steps

Parallel steps

The new parallel helper runs up to 8 independent steps at the same time and waits for all of them before the flow continues. Each step gets its own copy of the shared state.

When the steps finish, their changes to the shared state are merged by a reducer you provide. If two steps write the same key and no reducer is given, the flow stops with an error instead of keeping one of the values.

Checkpoints

Checkpoints are now written once per parallel group rather than once per step, which cut checkpoint writes by about two thirds in the project's own benchmark flow.

Breaking changes

Python 3.10 is no longer supported. The old sequence helper is renamed chain, and the old name prints a warning until 1.0.
