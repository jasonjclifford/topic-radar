Evaluating coding agents in production: a sampling method and what it found

Method

We sample 2 percent of live agent sessions each day and score each one against a rubric of five checks: did it finish, did the tests pass, did it stay inside the allowed files, did it ask when unsure, and was the result reviewed by a person.

Scoring is done by a model judge. To check the judge, two engineers labelled 200 sessions by hand, and the judge agreed with them on 87 percent of the labels.

Results

In the first month, 14 percent of sampled sessions failed without any error message, mostly because the agent stopped after a tool call returned an empty result.

After we changed the tool to return a plain sentence when a result is empty, the silent failure rate fell to 6 percent.

Judging costs about 0.4 cents per session, so the sample costs less than one engineer-hour a month.

Limits

The judge is weakest on the check about staying inside the allowed files, where it agreed with people only 71 percent of the time, so we compute that check from the file list instead.
