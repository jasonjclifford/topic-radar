Meridian 2 launches with a one million token context window and lower prices

What is new

Meridian 2 accepts up to 1,000,000 tokens of input in a single request, five times the context of the first Meridian.

Input now costs 2 dollars per million tokens, down from 3 dollars, and output costs 10 dollars per million tokens.

Speed and tools

Time to first token on a 100,000 token prompt is 40 percent shorter than before, and the model can now call up to 20 tools in one turn.

Prompt caching is available from launch, and cached input is billed at one tenth of the normal rate.

Availability

Meridian 2 is available today through the API and will reach the cloud marketplaces next week.
