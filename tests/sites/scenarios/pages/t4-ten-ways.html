10 ways to get more from GitHub Copilot

The list

1. Keep an instruction file in the repository with your project's rules, such as the test command and the code style.

2. Pick the right model for each task: a fast model for small edits and a larger one for design work.

3. Write small, clear prompts and say what done looks like.

4. Open the files that matter before you ask a question.

5. Ask for a plan before asking for code.

6. Read every diff before you accept it.

7. Keep chat sessions short and start fresh when the topic changes.

8. Use the built-in commands for tests and explanations.

9. Review suggestions the same way you review a teammate's pull request.

10. Share the habits that work with your team.
