How prompt caching cuts the bill on long agent sessions

The idea

Agents send the same instructions and files in every request. Prompt caching lets the provider remember that shared prefix, so repeated input is billed at a lower rate.

Put the stable parts of the prompt first and the changing parts last, so the cached prefix stays valid from one request to the next.

In practice

Long sessions benefit most, because the same prefix is reused many times. Short one-off questions barely benefit.
