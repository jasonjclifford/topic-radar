Claude Code 2.4 adds a PreCompact hook and per-subagent tool limits

What's new in 2.4

The new PreCompact hook runs a command just before Claude Code compacts the conversation. The command receives the transcript path on standard input and can print up to 2,000 characters of notes that are kept in the summary.

A subagent file can now set max_tool_calls. A subagent that reaches 30 tool calls is stopped and returns what it has found so far, which keeps a runaway search from using the whole budget.

Subagents that do not name a model now use the small model by default instead of the main session's model. Sessions that fan out many subagents should see lower token cost with no change to their files.

Hooks

The default hook timeout is now 60 seconds, up from 30 seconds, so a slow formatter no longer gets cut off.

Hooks defined in the old hooks.json file are still read in 2.4, but support for that file ends in 2.6. Move them into settings.json before then.

Other changes

The /context command now shows how many tokens each running subagent has used.

Fixed a crash that happened when two hooks wrote to the same log file at the same moment.
